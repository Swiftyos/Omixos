# Backgrounds

Every theme ships with its own set of backgrounds, and you can add extras of
your own in writable `~/.config/omarchy/backgrounds/[theme]`. The Nix runtime
defaults stay immutable; user backgrounds are intentionally outside the store.

Copy a file into the theme directory with Nautilus or the terminal, then choose
it with `Super + Ctrl + Space`. The upstream _Install > Style > Background_
entry is not a package installer on OmixOS.

You can find a huge collection of cool curated backgrounds on https://github.com/dharmx/walls.
